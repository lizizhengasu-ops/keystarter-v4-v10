## 一、三重结构分析

### 1.1 结构分析（组件树 + 数据流）

```
ProductPage
├── 顶部产品区（grid 2列）
│   ├── 左：产品图占位
│   └── 右：标题/价格/按钮/信任徽章
│       └── 长描述 <p>（第152行） ← 本次改造点：改为「短句 + 标签组」
├── 子网格（2列）
│   ├── leftCol：Features（功能卡片）
│   ├── rightCol：Product Details + How It Works
│   └── reqCol：System Requirements（跨列全宽，内部2列）← 已在上次完成
├── ProductComparison（对比表）← 内容精准化，结构不变
├── ProductFAQ（FAQ）
└── ProductReviews（评论）
```

数据源：
- `src/data/product-details.ts`：desc / features / requirements（27 个产品）
- `src/data/product-comparison.ts`：对比行数据
- `src/pages/Product.tsx`：渲染逻辑（第152行 desc 渲染）

### 1.2 行为分析（状态与渲染）

- `details` 来自 PRODUCT_DETAILS[slug]，`desc` 当前直接渲染为长段落
- 改造后：`desc` 保留为完整描述（供 SEO/完整内容），新增 `tags: string[]` 用于标签展示
- 渲染：`<p>` 短句 + 标签行，不动 addToCart/buyNow/reviews 等任何交互

### 1.3 样式兼容性分析

- 标签样式沿用现有设计令牌：`bg-[#7c3aed]/10 text-[#7c3aed] rounded-full px-2.5 py-1 text-[11px]`
- 对比表保持 `<div>` 行结构，仅改 rows 数据内容
- 不引入新依赖，不改变页面路由/布局容器

## 二、方案与完整代码

### 2.1 product-details.ts 扩展（接口 + 示例）

```typescript
export interface ProductDetail {
  desc: string;
  tags: string[];          // 新增：4-6 个短标签
  features: string[];

}
```

示例（windows-11-home-official）：
```typescript
PRODUCT_DETAILS['windows-11-home-official'] = {
  desc: 'Official Microsoft order with screenshot proof. Standard Windows 11 Home experience for daily use.',
  tags: ['Official Order', 'Screenshot Proof', 'Snap Layouts', 'Microsoft Teams', 'DirectX 12', 'Lifetime License'],
  features: [ ...保留现状... ],
  requirements: [ ...保留现状... ],
};
```

### 2.2 Product.tsx 渲染（第152行替换）

```tsx
<div className="mb-6">
  <p className="text-sm text-[#86868b]">{details ? details.desc : product.description?.substring(0,120)}</p>
  {details?.tags && details.tags.length > 0 && (
    <div className="flex flex-wrap gap-1.5 mt-3">
      {details.tags.map((tag, i) => (
        <span key={i} className="bg-[#7c3aed]/10 text-[#7c3aed] rounded-full px-2.5 py-1 text-[11px] font-medium">{tag}</span>
      ))}
    </div>
  )}
</div>
```

说明：因 Rolldown 的 brace-nesting 限制，`details?.tags` 若需要条件渲染，会放在预计算变量 `descBlock` 中，避免 JSX 内嵌复杂表达式。
