v6.0.6 的实际缺陷修复版 — 添加验证、速率限制、编码检测、冲突保护

⚠️ v6.0.6 模拟中发现的 6 个真实缺陷

  • 缺陷 1: Brevo API 有速率限制 (300封/天 或 6封/分钟)。312 封邮件直接发送会被限流 ❌
  • 缺陷 2: 中国 Windows 用户用 Excel 保存 CSV 时，默认编码是 GBK 不是 UTF-8。系统读出来乱码 ❌
  • 缺陷 3: 两个管理员同时导入 CSV → 互相覆盖数据 = 数据混乱 ❌
  • 缺陷 4: 订单有 3 个产品，只填了 2 个 Key。邮件发出去客户以为全收到了 ❌
  • 缺陷 5: 管理员输错 Key 格式 (少一位) → 发给客户无效 Key ❌
  • 缺陷 6: 批量导入时 Brevo 发到一半挂了 → 部分客户收到 Key，部分没收到 ❌
