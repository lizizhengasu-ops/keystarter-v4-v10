# v6.1.2 边缘场景模拟测试报告
## 目标: 验证 12 个真实边缘场景, 找出盲区

---

## 测试 1: CSV 包含 BOM 头部
**场景:** Excel 保存的 CSV 带 UTF-8 BOM (EF BB BF)
**操作:** 上传带 BOM 的 CSV
**预期:** 系统跳过 BOM，正常解析表头
**结果:** ✅ v6.1.2 有编码检测，自动识别 BOM

## 测试 2: CSV Key 列为空 (部分跳过)
**场景:** 管理员只填了 200 个 Key，112 行 Key 列为空
**操作:** 上传 CSV
**预期:** 跳过空 Key 行，只处理有 Key 的行
**结果:** ✅ v6.1.2 设计为跳过空值

## 测试 3: CSV 中订单 ID 不存在
**场景:** 有人手动改 CSV，把 #681 改成了 #9999 (不存在的订单)
**操作:** 系统读取 #9999 行
**预期:** 报警 "Order #9999 not found" 并跳过该行
**结果:** ❌ v6.1.2 未设计订单存在性校验
**缺陷等级:** 中 — 分配 Key 到不存在订单，数据丢失

## 测试 4: CSV 中产品 Slug 不匹配
**场景:** 产品 Slug 被人改了 (如 windows-11-pro → windows-11-pro-v2)
**操作:** 系统用旧 Slug 匹配产品
**预期:** 按产品名称回退匹配
**结果:** ❌ v6.1.2 未设计回退匹配逻辑
**缺陷等级:** 高 — Key 分配不到正确产品

## 测试 5: CSV 重复行
**场景:** 同一个订单的同一产品在 CSV 中出现 2 次
**操作:** 系统处理重复行
**预期:** 给该订单分配 2 个 Key (如果 Qty 匹配) 或报警
**结果:** ⚠️ v6.1.2 未处理重复行 — 可能导致同一个产品被分配 2 个额外 Key
**缺陷等级:** 中

## 测试 6: Key 含特殊字符
**场景:** Key 中包含 + = / 等 CSV 特殊字符
**操作:** CSV 解析
**预期:** 正确识别 Key 中的特殊字符
**结果:** ✅ CSV 标准格式可处理 (引号包裹即可)

## 测试 7: Brevo API 中途失效
**场景:** 发送到 156 封时 Brevo API 返回 429 (限流) 或 500
**操作:** 系统继续尝试发送剩余 156 封
**预期:** 触发重试机制
**结果:** ✅ v6.1.2 有自动重试 (3 次)

## 测试 8: 网络断开
**场景:** CSV 导入过程中网络断开
**操作:** 已保存的 Key 和未保存的 Key
**预期:** 已保存的状态不丢失，下次可继续
**结果:** ❌ v6.1.2 未设计断点续传
**缺陷等级:** 高 — 300 个 Key 可能部分已保存，部分丢失

## 测试 9: 队列模式发送空 Key
**场景:** 管理员按 S (Send) 但 Key 字段为空
**操作:** 尝试发送空 Key
**预期:** 阻止发送并提示
**结果:** ✅ v6.1.2 有字段验证

## 测试 10: 订单状态中途被修改
**场景:** 管理员 A 在处理订单时，管理员 B 修改了该订单
**操作:** A 保存 Key 时订单已变化
**预期:** 检测到订单版本冲突
**结果:** ❌ v6.1.2 未设计乐观锁
**缺陷等级:** 中 — 可能导致 Key 分配到已取消的订单

## 测试 11: 客户邮箱无效
**场景:** 客户填的邮箱格式错误 (test@)
**操作:** 发送邮件
**预期:** 标记发送失败，记录错误原因
**结果:** @ 校验可做，但 Brevo 会返回发送失败 — ⚠️ 需要明确错误信息

## 测试 12: CSV 中同一订单不同产品的 Qty 总计 > 产品需求
**场景:** 订单 #681 需要 3 个 Key，CSV 填了 4 个
**操作:** 系统尝试分配 4 个 Key 给 3 个产品需求
**预期:** 报警并提示超额
**结果:** ❌ v6.1.2 未设计超额校验
**缺陷等级:** 中 — 多余的 Key 可能被静默丢弃

---

## 汇总

| 测试 | 场景 | v6.1.2 结果 | 缺陷等级 |
|:----:|------|:-----------:|:--------:|
| 1 | BOM 头部 | ✅ | — |
| 2 | Key 为空跳过 | ✅ | — |
| 3 | 订单不存在 | ❌ | 中 |
| 4 | Slug 不匹配 | ❌ | 高 |
| 5 | 重复行 | ⚠️ | 中 |
| 6 | 特殊字符 | ✅ | — |
| 7 | API 中途失效 | ✅ | — |
| 8 | 网络断开 | ❌ | 高 |
| 9 | 空 Key 发送 | ✅ | — |
| 10 | 订单状态冲突 | ❌ | 中 |
