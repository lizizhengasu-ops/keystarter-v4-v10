# 3 轮深度测试 — v6.1.3 安全/性能/数据竞争

---

## 第 1 轮: 安全与权限

### 测试 1.1: 非管理员访问 License Keys 页面
**场景:** 普通编辑角色访问 /wp-admin/admin.php?page=ks-license-keys
**预期:** 返回无权限提示
**v6.1.3:** 设计中有 current_user_can("manage_options") 检查 ✅
**结论:** 通过

### 测试 1.2: CSRF 保护 (Import 操作)
**场景:** 攻击者诱导管理员点击恶意链接 → 触发 CSV 导入
**预期:** 导入时需要 wp_nonce_field() 校验
**v6.1.3:** ⚠️ 未显式说明使用 nonce
**结论:** ❌ 失败 — 无 CSRF 保护，攻击者可伪造导入请求

### 测试 1.3: XSS — Key 数据在管理页面显示
**场景:** Key 中包含 <script>alert('xss')</script>
**操作:** 管理员打开 License Keys 页面显示该 Key
**预期:** 系统使用 esc_html() 或 esc_attr() 转义输出
**v6.1.3:** ⚠️ 未显式说明输出转义
**结论:** ❌ 失败 — 存在 XSS 风险

### 测试 1.4: SQL 注入 — CSV 数据写入数据库
**场景:** Key 字段中包含 '; DROP TABLE wp_options; --
**操作:** 系统读取 CSV 并将 Key 写入数据库
**预期:** 使用 $wpdb->prepare() 或 update_meta_data() (已转义)
**v6.1.3:** update_meta_data() 使用 WordPress 预处理 ✅
**结论:** 通过

**第 1 轮结果: 4 项测试, 2 项失败 ❌**

## 第 2 轮: PHP 执行限制

### 测试 2.1: PHP max_execution_time (30 秒默认)
**场景:** 312 封邮件, 分批发送 (10封/批 × 10秒间隔 = 31批)
**计算:** 31 批 × 10秒等待 = 310秒 等待时间 + 发送时间 ≈ 320秒
**PHP 默认 max_execution_time:** 30 秒
**v6.1.3:** 发送循环在 30 秒后被强制终止 ❌
**修复:** 分解为 AJAX 任务队列, 每次请求只发一批

### 测试 2.2: 大 CSV 文件内存
**场景:** 100 订单 × 3 产品 = 347 行, 每行 ~200 字节
**文件大小:** ~70KB — 极小, 无压力 ✅

### 测试 2.3: 浏览器超时 / 管理员关闭页面
**场景:** 管理员开始导入后关闭浏览器标签页
**预期:** 已保存的 Key 不丢失
**v6.1.3:** 每批保存后提交, 浏览器关闭不丢失 ✅
**但:** PHP 后台可能继续执行, 占用 PHP-FPM 进程
**结论:** ⚠️ 需要设置超时保护

**第 2 轮结果: 3 项测试, 1 项失败 ❌, 1 项部分 ⚠️**

## 第 3 轮: 数据竞争条件

### 测试 3.1: 同一 Key 被分配到两个订单
**场景:** CSV 中同一个 Key 出现在两行 (手动复制错误)
**操作:** 系统先处理 #681 分配 Key, 后处理 #682 分配同一 Key
**预期:** 检测到 Key 已分配 → 报警阻止
**v6.1.3:** ❌ 未设计 Key 唯一性检查
**结论:** 失败 — 同一 Key 可能发给两个客户

### 测试 3.2: 导入 + 队列同时进行
**场景:** 管理员 A 在队列模式处理 #681
         管理员 B 同时导入 CSV 也包含 #681
**预期:** 锁机制阻止同时操作同一订单
**v6.1.3:** 有导入锁 (防止多人同时导入), 但队列和导入之间无互斥 ❌
**结论:** 失败 — 两模式可能互相覆盖

### 测试 3.3: 导入过程中订单被删除
**场景:** 系统正在处理 #789, 此时 #789 被管理员删除
**操作:** 系统尝试保存 Key 到不存在的订单
**预期:** 检测订单存在性 → 跳过
**v6.1.3:** 有订单存在性检查 ✅
**结论:** 通过

**第 3 轮结果: 3 项测试, 2 项失败 ❌**

## v6.1.4 修复计划

| 缺陷 | 修复方案 |
|------|---------|
| CSRF 无保护 | 导入表单加 wp_nonce_field('ks_import_csv') |
| XSS 风险 | 所有 Key 输出用 esc_html() / esc_attr() |
| PHP 超时 | AJAX 分片处理, 每次请求只处理一批 (10 封) |
| Key 重复分配 | 保存前检查 Key 是否已存在 meta_key = '_license_key_***' AND meta_value = '{key}' |
| 队列/导入互斥 | 订单级别锁: wp_cache_add("ks_order_lock_{id}", true, '', 30) |
