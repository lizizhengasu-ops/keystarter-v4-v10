# v6.0.6 — 100 订单处理模拟测试
## 场景: 100 个客户同时下单，共 347 个产品需分配 Key

---

## 模拟 A: CSV 批量模式 (推荐处理大量订单)

### Step 1: 导出 CSV (耗时: 10 秒)
系统导出pending_orders.csv:

`csv
Order#,Customer,Product Slug,Product Name,Qty,Key,Status
#681,Alice Wang,windows-11-pro,Windows 11 Pro OEM Key,1,,pending
#681,Alice Wang,office-2021-pro-plus,Office 2021 Professional Plus,1,,pending
#681,Alice Wang,win-svr-iot-2025,Win Svr IoT Std 2025,1,,physical
#682,Bob Chen,windows-10-pro,Windows 10 Pro OEM Key,2,,pending
#682,Bob Chen,windows-10-pro,Windows 10 Pro OEM Key,2,,pending
...(共 347 行)
`

### Step 2: 填写 Key (耗时: 3 分钟)

管理员打开 Excel，从自己的 Key 来源复制 Key，粘贴到"Key"列：

`csv
#681,windows-11-pro,Windows 11 Pro OEM Key,1,WX11P-A001-B002-C003,ready
#681,office-2021-pro-plus,Office 2021 Professional Plus,1,OFF21-D004-E005-F006,ready
#681,win-svr-iot-2025,Win Svr IoT Std 2025,1,,physical(贴纸)
#682,windows-10-pro,Windows 10 Pro OEM Key,2,WX10P-G007-H008-I009,ready
#682,windows-10-pro,Windows 10 Pro OEM Key,2,WX10P-J010-K011-L012,ready
...(347 行中 312 个填了 Key, 35 个实体产品留空)
`

### Step 3: 上传并处理 (耗时: 1 分钟)

系统上传 CSV，执行:

`
[VALIDATION]
  ✓ 347 行格式正确
  ✓ 312 个 Key 符合各自产品的格式规则
  ✓ 35 个实体产品已跳过(不需 Key)
  ⚠ 0 个 Key 格式错误(无需修正)

[PROCESSING]
  → 批量保存 312 个 Key 到对应订单的产品
  → 通过 Brevo 发送 312 封邮件
  → 35 个实体产品标记为"待发货"
  → 更新订单状态

[RESULT]
  ├─ 312/312 邮件发送成功 ✅
  ├─ 0 发送失败
  ├─ 35 个实体待发货
  └─ 总计耗时: 4 分 10 秒
`

### 验证点

| 检查 | 结果 |
|------|:----:|
| Key 有没有分配给正确的产品？ | 每行有 Product Slug 精确匹配 ✅ |
| 同个产品 2 个 Key 会不会乱？ | 同一行 ×2 自动分配 2 个 Key ✅ |
| 实体产品跳过？ | physical 标记的跳过 Key 字段 ✅ |
| 邮件发送失败怎么处理？ | 每封独立状态，失败的标记后可重试 ✅ |
| 用户收到邮件后 Key 是否正确？ | 系统按 Slug 匹配，数据层已验证 ✅ |

## 模拟 B: 队列模式 (日常处理 10-15 单)

### 操作流程

`
管理员打开 License Keys → Queue Mode
                                      
┌─ Queue ────────────────────────┐
│ #681 Alice Wang (3 min) ◀ 正在处理  │
│ #682 Bob Chen (5 min)               │
│ #683 Carol D. (7 min)               │
│ ...                                 │
│ 快捷键: N=下一个, S=发送, C=完成    │
└────────────────────────────────────┘

每单操作:
  1. 看到订单 → 从自己的来源获取 Key (5-10 秒)
  2. 粘贴到产品输入框 (2 秒)
  3. 按 S 键 → 保存 + 发邮件 + 自动跳到下一单 (1 秒)
  ──────────────────────────
  每单 ≈ 13 秒

15 单 × 13 秒 = 3.25 分钟 ✅
`

### 日常使用验证

| 场景 | 时间 | 结论 |
|------|:----:|:----:|
| 早上到公司处理前夜订单 (20 单) | 4.3 分钟 | ✅ 可行 |
| 午休后处理上午订单 (12 单) | 2.6 分钟 | ✅ 可行 |
| 下班前收尾 (8 单) | 1.7 分钟 | ✅ 可行 |
| 突发大促 100 单 | 21.7 分钟 | ⚠️ 建议切换到 CSV 模式 |
