# v6.1.6 License Keys System 操作指南

> 版本: 6.1.6 | 最后更新: 2026-07-27
> 作者: Codex + KeyStarter 团队
> 本指南旨在让任何具备基本 WP Admin 操作能力的人员都能独立完成 License Key 交付

---

## 概述

**License Keys** 是 KeyStarter 网站的 Key 交付管理工具
核心流程: 管理员手动输入 Key -> 系统自动发邮件给客户

入口: WP Admin -> WooCommerce -> License Keys
支持模式: 队列模式 (Queue) + CSV 批量模式
邮件通道: Brevo API，失败时降级为 wp_mail()
适用场景: 虚拟产品交付 (Key) + 实体产品物流跟踪

注意: 本系统不预存 Key 池，Key 由管理员在收到订单后从合作伙伴处获取再手动录入

---

## 一、队列模式 (Queue)

队列模式适合每天处理几十个订单的场景

### 如何进入
1. 登录 WordPress 后台
2. 左侧菜单找到 WooCommerce
3. 点击 License Keys
4. 默认进入 Queue 标签页

### 标准操作流程
1. 查看当前待处理的订单列表
2. 确认订单号和客户信息正确
3. 在产品右侧的输入框中粘贴 License Key
4. 点击 Skip -> Next 跳过当前订单
5. 点击 Save & Send Keys 保存并发送
6. 系统自动保存 Key、发送邮件、更新订单状态

### 快捷键
S = Save & Send Keys
N = Next Order

### 注意事项
- 每个虚拟产品一行，输入框为空表示尚未交付
- 实物产品显示 Physical product，不需要填 Key
- 同一订单所有 Key 填完后订单自动变为 Completed
- 重复 Key 会被系统自动跳过

## 二、CSV 批量模式

CSV 模式适合处理 50 个以上的订单，或合作伙伴提供 Excel 表格的场景

### Step 1: 下载待处理 CSV
切换到 CSV Batch 标签，点击 Download CSV

### Step 2: 编辑 CSV 填入 Key
用 Excel 打开 ks-pending-keys.csv

CSV 格式:
Order#,Product Slug,Product Name,Key
681,windows-11-pro,Windows 11 Pro OEM Key,WX11P-ABCD-EFGH-IJKL
682,office-2021-pro-plus,Office 2021 Professional Plus,OFF21-MNOP-QRST-UVWX

编辑规则:
- 不要修改 Order# 和 Product Slug 列
- Key 列填入许可证
- 一行一个 Key，多份产品需要多行
- 保存时选择 CSV UTF-8 格式

### Step 3: 上传并处理
回到 CSV Batch 页面 -> 选择文件 -> Upload & Process

### Step 4: 检查处理结果
Imported: N keys (ok)
skipped: N (跳过)
Errors: ... (错误详情)

### 注意事项
- 文件编码必须为 UTF-8
- 最大文件大小 10MB
- 重复 Key 自动跳过
- 订单处理中会锁定 300 秒

## 四、完整订单交付流程

### 客户下单
客户前端选择产品 -> 加入购物车 -> 点击 Checkout
转向 WooCommerce 结算页
选择 PayPal 支付
跳转 PayPal 登录 -> 确认付款
返回网站 -> WooCommerce 创建订单，状态: processing

### 管理员交付
收到新订单通知 -> 进入 License Keys -> Queue 模式
确认订单信息
从合作伙伴处获取 Key
在输入框中粘贴 Key -> 点击 Save & Send Keys
系统自动发送邮件给客户
订单状态变为 Completed

### 客户收到
客户收到来自 KeyStarter <noreply@keys-starter.com> 的邮件
邮件包含订单编号、产品名称、License Key

### 实物产品处理
License Keys 页面显示 Physical product
完成物流发货后在订单备注中填写物流单号
手动将订单状态改为 Completed

## 五、常见问题

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 页面一直转圈 | PHP 执行超时 30s | 减少订单量，分批次处理 |
| CSV 导入失败 | 编码不是 UTF-8 | 重新下载模板，另存为 CSV UTF-8 |
| 客户没收到邮件 | 邮箱错误 / Brevo 限额超 | 点 Resend，检查 Brevo 控制台 |
| 订单没变 Completed | 还有产品没填 Key | 填完所有虚拟产品的 Key |
| 多人同时操作同一订单 | 并发冲突 | 等 5 分钟后重试 |
| Key 提交后提示重复 | 已分配给其他订单 | 找合作伙伴换新 Key |
| 实物产品也要求填 Key | Virtual 标记错误 | 联系技术修复产品设置 |
| 邮件进了垃圾箱 | SPF/DKIM 配置问题 | 检查 Cloudflare DNS 记录 |

## 六、技术架构

插件主文件: /var/www/keys-starter.com/wp-content/plugins/keystarter-email-api/keystarter-email-api.php

核心结构:
- admin_menu: 注册子菜单
- ks_render_queue: 队列模式页面
- ks_render_csv: CSV 批量页面
- ks_order_lock: 订单并发锁 (300s)
- Dashboard widget: 首页小工具
- admin_init: 保存 + 发送处理器

安全机制:
- CSRF: wp_nonce_field() 保护
- XSS: esc_html() / esc_attr() 转义
- Key 去重: 数据库查重
- 权限: 仅 manage_woocommerce 角色可访问
- 文件大小: CSV 最大 10MB
- 并发控制: 300s 订单锁

- 检查插件和主题更新
- 检查 WooCommerce 订单统计

## 九、操作人员注意事项

### Key 输入
- 优先使用复制粘贴，避免手动输入错误
- Key 格式: PRODUCT-XXXX-XXXX-XXXX
- 注意 0 (数字) 和 O (字母) 的区分

### 批量操作
- 少于 20 个订单: 用 Queue 模式
- 20-50 个: 可以用 Queue 或 CSV
- 超过 50 个: 建议用 CSV 模式
- 超过 200 个: 分多个 CSV 文件上传

### 多人协作
- 不要同时操作同一个订单
- 看到 Order locked 等 5 分钟后重试
- 建议按时间段分工

### 紧急情况
- 邮件发送失败: 手动复制 Key 通过其他渠道发给客户
- 插件崩溃: 联系技术重新激活
- Key 被重复分配: 联系合作伙伴重新获取
