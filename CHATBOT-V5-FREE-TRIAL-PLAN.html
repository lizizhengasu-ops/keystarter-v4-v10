ChatBot V5 — 7 天免费试用方案

基于 V4 全量方案 + 新增免费试用逻辑

⚠️ 不覆盖 V4。V5 在 V4 基础上增加免费试用机制。V4 文件保留用于对比。

一、试用逻辑

核心规则：

• 新客户注册 → 自动获得 7 天免费试用
• 试用期内：全部功能可用（AI 聊天、知识库、聊天记录查看）
• 试用结束后：必须付款才能继续使用
• 每个邮箱/域名只能试用一次
• 试用到期后不付款 → 跟付费到期一样返回 403

计费状态流转：
新注册 → trial（7天）→ 到期 → expired → 付款 → active（30天）→ 到期 → expired
新注册 → trial（7天）→ 第3天付款 → active（30天从付款日起算）
trial 到期 → 第10天才付款 → active（30天从付款日起算）

无论客户什么时候付款，都是从付款日 +30 天到期。试用天数不折算。

二、数据库变化

tenants 表新增字段：
  trial_started_at TEXT   -- 试用开始日期，NULL=未试用过
  trial_used INTEGER DEFAULT 0   -- 0=未用过试用，1=已用过

status 可选值：
  'inactive'  → 刚注册，未激活
  'trial'     → 试用中
  'active'    → 已付款，正常服务
  'expired'   → 到期（试用到期或付款到期）

三、续费横幅逻辑（分情况）

状态总时长横幅出现时间横幅内容
试用期7 天第 5 天开始还剩 X 天试用结束，立即付费
付费期30 天第 20 天开始（=剩 10 天）还剩 X 天到期，立即续费
横幅显示位置：
• 客户后台（dashboard.你的域名）顶部 — 每次登录都看到
• WordPress 插件后台（如果用了插件版）— 插件设置页顶部
• 不在终端用户的聊天浮窗里显示

四、两条路径的试用流程

路径 A：WordPress 插件

1. 下载安装插件
2. 在插件设置页输入邮箱注册
3. 系统发验证邮件
4. 验证通过 → 7 天试用开始
5. 插件显示倒计时
6. 到期 → 插件设置页显示付款二维码
7. 付了 → 30 天正常使用

路径 B：预嵌入建站

1. 你给客户建好站
2. 客户登录后台 → 「AI 聊天机器人」菜单
3. 点击「开始 7 天免费试用」
4. 试用开始 → 聊天浮窗出现
5. dashboard 显示倒计时
6. 到期 → dashboard 显示付款二维码
7. 付了 → 30 天正常使用

五、防止滥用

• 一个邮箱只能试一次（数据库 unique 约束 + 验证邮件）
• 一个域名只能试一次（域名白名单里记录已用过的域名）
• 试用结束 → 必须付款 → 没有第二次试用
• 一个黑名单邮箱（临时邮箱）列表可以后续加上
• 技术上跟付费用户用同一套 Worker 和 KB 目录，没有区别对待

六、定时任务逻辑（更新）

每天凌晨定时任务：

FOR EACH tenant:
  IF status = 'trial' AND expires_at < now:
    status = 'expired'
    trial_used = 1
    （不删除 KB，保留数据，付款后恢复）

  IF status = 'active' AND expires_at < now:
    status = 'expired'

  IF (status = 'trial' AND expires_at - now <= 2 days):
    renewal_banner = 1（试用到期提醒）

  IF (status = 'active' AND expires_at - now <= 10 days):
    renewal_banner = 1（付费到期提醒）

七、跟 V4 的关系

V5 不改变 V4 的任何架构设计。只在 V4 基础上增加：

• tenants 表 +2 字段
• status +1 个可选值（'trial'）
• 注册时无付款 → 自动 7 天试用
• 横幅逻辑分情况（试用剩 2 天 / 付费剩 10 天）
• 定时任务增加 trial 过期检查
• 防止滥用机制（邮箱+域名唯一）
