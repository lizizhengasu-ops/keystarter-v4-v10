每个 chatbot 从自己的对话中学习，自动优化话术和知识库

行业通用做法：日志 → 分析 → 建议 → 确认 → 更新。不自动上线，需人工确认。

架构

两层分离：

层 1 — 对话日志（实时）：每次对话结束后，整段对话写入 /kb/tenant_X/conversations/YYY-MM-DD.jsonl
层 2 — 定时分析（每日）：每天凌晨，用 DeepSeek 批量分析日志，输出建议。

不自动更新知识库。AI 只生产建议，你自己（或客户）审核后确认。

对话日志格式

{ "tenant": "client_a", "session_id": "abc123", "timestamp": "2026-07-11T14:32:00Z", "messages": [ {"role": "customer", "text": "Windows 11 Pro多少钱"}, {"role": "ai", "text": "$19.99...", "intent": "PRODUCT_QUESTION"}, {"role": "customer", "text": "太贵了"}, {"role": "ai", "text": "市场价$199...", "intent": "PRICE_OBJECTION"} ], "resolved": true, "purchase_made": false }

每日分析（空闲时运行）

每天凌晨，对每个租户独立执行：

1. 提取未回答问题：
扫描对话日志中的 customer 消息，找出 AI 没有回答（OOS 响应）的问题。
→ 建议：添加到 FAQ。

2. 识别高频问题：
统计最近 7 天内客户问得最多的问题。
→ 如果知识库里没有，建议补充。如果已经有了，确认回答是否准确。

3. 分析成交模式：
对比"最终购买了"和"没购买"的对话，找出差异。
→ 什么话术让客户下单了？什么话术让客户走了？
→ 输出：话术优化建议。

4. 结果存储：
分析结果写入 /kb/tenant_X/recommendations/YYY-MM-DD.json
客户在 Dashboard 的「进化建议」栏目里看到，人工确认后一键应用。

Dashboard 新增栏目

客户在 Dashboard 的 AI 聊天机器人菜单下，新增：

📈 进化建议
• 建议新增的 FAQ（由 AI 分析对话自动生成）
• 建议优化的产品描述
• 话术改进提示
• 每个建议都带来源对话链接
• 一键确认/忽略

🗣️ 对话日志
• 查看最近的对话记录
• 搜索特定问题
• 标记有用/无用的回答

技术实现

对话日志：每次 WebSocket 会话结束时，Worker 写入 JSONL 文件。代码约 30 行。

每日分析：一个 Node.js 脚本，用 DeepSeek 分析日志。代码约 100 行。

Dashboard 展示：前端列表页 + 确认按钮。代码约 150 行。

工作量：约 1 天（Codex 时间）。

API 成本：每天每租户分析一次，每次约 2000 tokens。DeepSeek 价格 ≈ 忽略不计。

跟 V8.3 的关系

V8.4 在 V8.3 基础上增加对话学习能力。V8.3 的所有框架（意图识别、KB兼容性、无关信息处理、四修复）不变。不影响现有流程。
