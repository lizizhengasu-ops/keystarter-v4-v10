步骤 1/8 — 访客打开客户网站

1/8
1客户 VPS➡️访客浏览器输出 HTML，含 widget.js 脚本标签
2访客浏览器➡️你的 VPS请求 widget.js（HTTPS）
3你的 VPS➡️访客浏览器返回 widget.js（混淆压缩）
4访客浏览器➡️你的 VPS建立 WebSocket → 发送加密 token
5你的 VPS➡️访客浏览器验证 token ✅ 域名 ✅ 订阅 ✅ → OK
6访客浏览器➡️你的 VPS访客打字提问 → 通过 WebSocket 发送
7你的 VPS➡️访客浏览器查知识库 → 调 DeepSeek → 返回回答
8你的 VPS➡️内部记录日志 → 更新用量 → 检查过期
🔗 关键：WebSocket 长连接（步骤 4 后持续）
访客浏览器 ↔ 你的 VPS  |  客户 VPS 不在连接中
整个对话周期，客户 VPS 只做一件事：最初那一次输出 HTML。
🎯 核心结论：客户 VPS 和你的 VPS 不直接通信。路径是 客户 VPS → 浏览器 → 你的 VPS（再反向）。浏览器是唯一桥梁。客户 VPS 输出页面后不再参与。客户用哪家 VPS 都不影响。
