V8.2 — KB 驱动的兼容性框架

核心变化：AI 不硬编码任何产品兼容性问题，全靠读知识库自己判断

一、之前错在哪

V8.1 的错误写法（硬编码）：
IF store sells software → ask about OS and RAM IF store sells furniture → ask about room dimensions IF store sells clothing → ask about size
这样换了产品类别就要改代码。不通用。

V8.2 的正确写法（KB 驱动）：
For every product, check if it has a "compatibility" field in the KB. If yes → ask the customer about that field. If no → give a generic "please check" guidance.
AI 不关心店卖什么。它只读 KB 里的数据，有就问，没有就不问。

二、KB 数据示例

卖软件的知识库（products.json 示例）：
[ { "name": "Windows 11 Pro", "price": 19.99, "compatibility": "Requires Windows 10 or newer, 64-bit processor, 4GB RAM" }, { "name": "Gaming Chair", "price": 299, "compatibility": "Supports up to 150kg, seat height 45-55cm" } ]

AI 读取后自动生成的提问：
• 看到 Windows 11 Pro 的 compatibility → 问"你的系统是 Win 10 以上吗？内存够 4GB 吗？"
• 看到 Gaming Chair 的 compatibility → 问"你的体重在 150kg 以下吗？桌面高度合适吗？"

不需要写 if-else。AI 读到了就是读到了。没读到就不问。

三、系统提示词（兼容性部分）

## COMPATIBILITY HANDLING (generic, KB-driven) When a customer asks about compatibility, fit, or whether a product works for them: 1. Read the product(s) in the Knowledge Base 2. Check if the product has a "compatibility" field 3. If the compatibility field exists: - Ask the customer about the specific requirements listed in that field - Use the EXACT wording from the field, not a generic question - Example: if field says "Requires Windows 10+", ask "Are you on Windows 10 or newer?" 4. If the product does NOT have a compatibility field: - Tell the customer: "I don't have specific compatibility data for this product. Here is what I recommend checking: [general guidance based on product type]" 5. After confirming compatibility → proceed to recommendation or purchase IMPORTANT: Never hardcode what to ask. Always derive the question from the KB data.

四、Dashboard 操作

客户在 Dashboard 的「产品管理」栏目中，每个产品可以填一个「兼容性要求」字段。

• 填了 → AI 自动问客户相关问题
• 没填 → AI 不提问，或给通用指导
• 客户随时可以修改

这个字段不是必填的。但填了能提高成交率——客户知道产品适合自己，更敢下单。

五、跟之前版本的关系

V8.1 → V8.2 的唯一变化：
兼容性处理从「按产品类别硬编码」改成「全由 KB 驱动」。

V8.1 的提示词里有 if-else 判断（如果软件就...如果家具就...）。
V8.2 删掉了所有 if-else，改成：
每个产品读 compatibility 字段 → 有就按字段问 → 没有就不问
其他部分（意图识别、四修复、Dashboard）不变。
