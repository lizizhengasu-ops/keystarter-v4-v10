阶段一：你给中国老板建站+预埋机器人 建站时就装好了

🟣 你做的事

1. 给中国老板建整套独立站（WordPress + WooCommerce + React SPA）
2. 聊天机器人组件已经预埋在前端代码里
3. 管理后台里已经有"AI 聊天机器人"菜单项
4. 部署到：客户的 VPS 或你的 VPS
5. 立即可用，不需要老板自己装任何东西

🟠 客户收到的

• 完整独立站（可卖商品给欧美）
• 网站已经带了聊天机器人
• 后台登录账号密码
• 后台左侧菜单有"AI聊天机器人"选项
• 点进去就能：付款开通 / 看聊天记录 / 配置机器人
💡 跟一般chatbot的区别：你不是给客户一行script叫他贴——你是给他建整套网站，机器人已经装好了。他什么都不用装。

阶段二：客户后台操作 登录后台 → 付款开通 → 看到数据

1/5
1🟠 客户➡️后台登录用账号密码登录独立站管理后台
2🟠 客户➡️左侧菜单看到"AI 聊天机器人"菜单项，点进去
3🟠 客户➡️🟣 你的 VPS看到付款页面 → 微信/支付宝扫码付 $99/月 或 $299/月
4🟣 你的 VPS➡️内部付款成功 → 激活 chatbot：创建该店的 KB 目录、生成 HMAC token、设置 expires_at=now+30天
5🟠 客户后台🟢面板AI 聊天机器人页面出现面板：聊天记录（每个终端的对话）、续费状态（还剩多少天）、配置（机器人名字、语气）
到期前10天：页面顶部显示黄色续费横幅，每天提醒
⚡ 关键：客户的聊天机器人页面里能看到 每个终端用户的聊天记录。这是他的卖点——他能看到消费者在关心什么，什么产品问得多。

阶段三：终端用户聊天 消费者在店里跟AI对话

1/6
1🟢 终端用户➡️浏览器打开独立站 → 右下角聊天浮窗已经显示（预埋的，不需要加载外部脚本）
2🟢 浏览器➡️🟣 你的 VPS直接 WebSocket 连接你的服务（chat.你的域名:3002），发送内置 token
3🟣 你的 VPS➡️内部验证验证 token → 确认是该店的机器人 → 检查订阅是否有效 ✅
4🟢 终端用户➡️🟣 你的 VPS打字："Windows 11 Pro 多少钱？" → WebSocket 发送到你的 VPS
5🟣 你的 VPS➡️AI 处理查该店的知识库（产品数据、FAQ）→ 调 DeepSeek → 只基于知识库回答
6🟣 你的 VPS➡️🟢 终端浏览器回复发回浮窗显示。同时记录到该店的聊天记录，客户后台里能看到
🔗 数据流：终端浏览器 ↔ 你的 VPS（WebSocket全程）。客户的VPS 不参与对话。预埋在代码里 ≠ 数据经过客户VPS。预埋只是在网站前端加了个组件，它直连你的VPS。

阶段四：多人多店场景 你控制全部，每店隔离

🟣

你的 VPS

🔹 店A 工人（独立进程）
🔹 店B 工人（独立进程）
🔹 店C 工人（独立进程）
...
每店独立 KB 目录
每店独立 Qdrant 集合
中国老板 A → 独立站（他的 VPS） → 机器人已预埋 → 后台付了费 → 能看聊天记录
中国老板 B → 独立站（你的 VPS） → 机器人已预埋 → 还没付费 → 后台显示付款页
中国老板 C → 独立站（他的 VPS） → 机器人已预埋 → 付了费但到期了 → 浮窗不工作

不管客户的站跑在谁的 VPS 上，预埋的机器人直连你的服务。
你 VPS 上运行 N 个 Worker 进程，每店一个。数据和知识库完全独立。
🧱 隔离：店A的工人看不到店B的产品数据。店B的工人看不到店C的FAQ。每店的知识库目录是独立的文件系统目录。

阶段五：计费生命周期

1/5
1🟣 你➡️系统客户付款后：expires_at = now+30天，状态 active。预埋的机器人开始工作
2🟣 你➡️每天定时每天凌晨检查所有店的 expires_at
3🟠 客户后台🟡≤10天还剩≤10天 → 后台 AI 聊天机器人页面顶部显示黄色横幅："还剩X天，立即续费"
4🟠 客户➡️🟣 你点续费 → 微信/支付宝再付 → expires_at +30天 → 横幅消失
5🟣 你⛔🟢 浮窗到期未续费 → status=expired → WebSocket 连接时返回 403 → 浮窗不显示 → AI 不回答
🎯 一句话总结：你给中国老板建整套独立站。机器人预埋在站里。老板后台付钱开通。终端用户跟AI聊。所有AI在你VPS上处理。每店独立隔离。老板到期的付钱才能继续用。
