阶段一：客户购买机器人 中国老板 → 你 → 激活

1/6
1🟠 客户➡️🟣 你打开你的收款页面 billing.你的域名，选套餐，付款
2🟠 客户➡️🟣 你微信/支付宝扫码支付 $99 或 $299
3🟣 你➡️内部服务器处理：创建租户配置 → 生成 HMAC token → 创建知识库目录 → 设置 expires_at = now+30天
4🟣 你➡️🟠 客户客户邮箱收到：portal 登录链接 + widget 嵌入代码
5🟠 客户➡️客户 VPS把代码贴到自己独立站的 HTML 中：<script src="https://chat.你的域名/w.js">
6🟠 客户➡️🟣 你登录 portal，上传产品数据、FAQ、政策，完善知识库
💰 关键：客户付款后 30 天倒计时开始。到期前 10 天 portal 显示续费横幅。不续费 → 自动停用。

阶段二：技术部署 客户 VPS → 终端用户浏览器 → 你的 VPS

1/4
1🟠 客户 VPS➡️🟢 终端用户浏览器独立站输出 HTML 页面，包含你的 widget script 标签。这是客户 VPS 唯一做的事
2🟢 终端用户浏览器➡️🟣 你的 VPS自动加载 widget.js（HTTPS GET），从你的服务器下载脚本
3🟣 你的 VPS➡️🟢 终端用户浏览器返回 widget.js（混淆压缩、无 sourcemap）。脚本执行，建立 WebSocket 连接
发送加密 HMAC token → 服务器验证订阅 ✅ 域名 ✅ → 连接建立
4🟢 终端用户浏览器⇄🟣 你的 VPSWebSocket 长连接持续存在。此后所有消息走这条线。
客户 VPS 不再参与。终端用户 VPS 都不用管是谁的。
🔗 核心：客户 VPS 和你的 VPS 不直接通信。路径是 客户 VPS → 终端浏览器 → 你的 VPS。加载完页面后客户 VPS 退出。终端用户的浏览器是唯一桥梁。

阶段三：终端用户提问 → AI 回答 完整消息链路

1/6
1🟢 终端用户➡️浏览器在客户独立站上看到右下角聊天气泡，点击打开，打字："Windows 11 Pro 多少钱？"
2🟢 终端浏览器➡️🟣 你的 VPS通过 WebSocket 发送消息 + HMAC token 到 chat.你的域名:3002
3🟣 你的 VPS➡️内部验证Master 进程：解密 token → 识别租户 → 域名白名单检查 ✅ → 订阅状态检查 ✅ → 路由到该租户的 Worker 进程
4🟣 你的 VPS➡️知识库Worker 进程：在租户独立的 KB 目录搜索 → 找到 Windows 11 Pro 价格 $19.99 → 准备上下文
5🟣 你的 VPS➡️AI 推理将产品数据 + FAQ + 用户问题组装成提示词 → 发给 DeepSeek → 只基于知识库回答，不编造
6🟣 你的 VPS➡️🟢 终端浏览器AI 回复通过 WebSocket 发回 → 浮窗显示"Windows 11 Pro 是 $19.99，商业授权"
同时记录日志、更新用量统计、检查过期状态

阶段四：多人多站场景 你控制全部，独立隔离

🟣

你的 VPS

租户 A 工人
租户 B 工人
租户 C 工人
...
每个独立进程
10 个中国老板 → 每人付款 $99-$299 → 各有一个独立 Worker 进程
各自独立站 → 可能在各自的 VPS 上，也可能在你这
终端用户 → 分布在欧美各国，各连各的 WebSocket

每个租户的 Worker：独立进程、独立 KB 目录、独立 Qdrant 集合、独立配置。互不可见。
你的控制：全部代码在你 VPS 上。客户 VPS 上只有一行 script 标签。
🧱 物理隔离：10 个客户 = 10 个独立进程 + 10 套独立知识库。每个进程只能读自己的数据。A 看不到 B 的产品数据。B 看不到 C 的 FAQ。互不影响。

阶段五：计费与续费 自动计时 · 到期停用

1/5
1🟣 你的 VPS➡️数据库付款成功 → 写入 expires_at = now + 30 天 → 状态 = active
2🟣 你的 VPS➡️每天定时任务每天凌晨检查所有租户：还剩多少天？
3🟠 客户 portal🟡≤10 天还剩≤10天 → portal 顶部显示"还剩 X 天，点击续费"黄色横幅（每天显示）
4🟠 客户➡️🟣 你客户点击续费 → 微信/支付宝再付一个月 → 服务器延长 expires_at +30 天
5🟣 你的 VPS⛔🟢 终端浏览器到期未续费 → 状态变 expired → Widget 每次连接返回 403"服务已到期" → AI 不回答
计时在服务器上，客户改不了。
